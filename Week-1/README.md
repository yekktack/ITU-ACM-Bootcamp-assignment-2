# Javascript/Typescript alıştırmaları

Bu alıştırmalar İTÜ ACM DevTeam 2026 Bootcamp kapsamında derse ek olarak
hazırlandı.

Klasörler isimlerindeki sıralamayla çözmenizi öneririm. Klasörler içerisinde
genellikle iki dosya var (.tester.js ve diğeri şeklinde), .tester.js dosyasına
dokunmayınız, bu dosya sizin kodunuzu test eden fonksiyonları içeriyor. Diğer
dosyada boş bırakılan fonksiyonları tamamlayarak egzersizi tamamlamanız
gerekmekte.

Kodunuzu test etmek için aşağıdaki komutu çalıştırmanız yeterli:
```
npm test
```

Çıkan hata mesajına göre ilgili egzersizdeki dosyayı düzeltmeniz gerekmektedir.

Takıldığınız bir yer olduğunda bana yazmaktan çekinmeyin!
