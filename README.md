# DevTeam Bootcamp 2026 Exercises

Bu repodaki alıştırmalar İTÜ ACM DevTeam 2026 Bootcamp kapsamında derse ek
olarak hazırlanmıştır.

## Klasörler

- `Week-1/` — JavaScript/TypeScript alıştırmaları (`npm test` ile kendi kendini
  kontrol eder)
- `Week-2/` — Ders 2'de canlı yazdığımız kod (referans)
- `project/` — **Ödev 2.** Kampın sonuna kadar üzerine ekleyeceğimiz Todo API
  projesi. Kurulum ve yapılacaklar için [`project/README.md`](project/README.md)

## Ödev nasıl yapılır

Bu repoyu fork'layın, `project/` klasöründe çalışın, `npm test` ile kendinizi
kontrol edin. Yeni haftalar eklendiğinde `git fetch upstream && git merge
upstream/master` ile güncellemeleri çekersiniz.
